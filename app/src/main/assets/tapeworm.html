The microphone continuously grows new segments. Each finished segment repeats a fixed number of times, fades proportionally with each pass, then drops off the worm. Playback never feeds the record path.

CAPTURE → REPEAT → FADE → SHED.

SPEED changes the spacing between segment launches without changing their pitch. PITCH changes how fast each individual segment is read. At 2× SPEED and 0 st PITCH, segments are packed twice as tightly while the voice inside each segment stays at its recorded pitch.
